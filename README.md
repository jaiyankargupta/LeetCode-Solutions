## Repository Overview

This repository serves as a personal archive of solved Data Structures & Algorithms (DSA) problems across LeetCode, GeeksforGeeks, and competitive programming platforms.

Every accepted submission is automatically analyzed, categorized by difficulty, and committed with comprehensive Big-O Time & Space complexity breakdowns.

### Key Features & Infrastructure
- **Live Web Platform**: [https://analzer.rustyn.me](https://analzer.rustyn.me)
- **Spaced Repetition Algorithm**: Automatic revision queues scheduled at 3-day, 7-day, 15-day, and 30-day intervals to eliminate forgetting curves and ensure long-term retention.
- **Groq AI Complexity Breakdown**: Instant, accurate Big-O time and space complexity evaluations generated for every accepted solution.
- **Automated Directory Organization**: Solutions categorized cleanly under `Easy/`, `Medium/`, and `Hard/` directories containing both source code and detailed problem notes.
- **Contests & POTD Tracking**: Live contest schedules (LeetCode, Codeforces, CodeChef, AtCoder) and daily Problem of the Day feeds synced directly across the Chrome Extension and Web Dashboard.
